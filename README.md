# Anna Fénypont Kozmetika – landing page

Egyoldalas, reszponzív weboldal (fehér háttér, kék szöveg) az abdai Anna Fénypont Kozmetikának.

- `index.html` – az oldal (saját CSS, külső függőség csak a Google Fonts)
- `img/` – logó, fotók és árlisták
- `robots.txt`

Megnyitás: nyisd meg az `index.html`-t böngészőben, vagy tedd fel Vercelre / GitHub Pagesre.
Az ünnepi nyitvatartás szakasz (`id="unnepek"`) karácsony után törölhető.
